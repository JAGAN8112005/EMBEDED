# LPC2148 Embedded Firmware & Peripheral Drivers

## Overview

This repository contains my embedded C implementations and learning projects
based on the **NXP LPC2148 ARM7 microcontroller**.

The projects focus on understanding microcontroller peripherals at the
**register level**, peripheral initialization, hardware interfaces,
communication protocols, interrupt handling, and RTOS concepts.

The purpose of this repository is to demonstrate my understanding of
low-level embedded firmware development and peripheral programming.

---

## Microcontroller

- **MCU:** NXP LPC2148
- **Core:** ARM7TDMI-S
- **Architecture:** 32-bit ARM
- **Programming Language:** Embedded C
- **Development Environment:** Keil µVision / ARM7 Toolchain
